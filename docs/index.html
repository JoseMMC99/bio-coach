  3. Agrega la acción "Diccionario" con las claves: sleep_hours, resting_hr, hrv_ms
  4. Agrega la acción "Obtener contenido de URL" en método POST:

    Encabezado apikey: sb_publishable_52J4Pni9JZK-iNcaoznbEg_YHbxCEi5
